Precision

Only orange hurts it. A prediction tucked entirely inside the object scores 1.00 even if it misses most of it.
Recall
–
TP / (TP + FN)
Of everything real, how much did I catch?
Only red hurts it. A prediction that swallows the object plus its neighbors still scores 1.00.
Dice
–
2TP / (2TP + FP + FN)
How well do the two masks overlap overall?
Harmonic mean of precision and recall, so it's high only when orange and red are both small. It doesn't say which error you made.

No true negatives. The empty background appears in none of these formulas, which is why they work for small objects in large volumes where pixel accuracy would look great even for an empty prediction.
